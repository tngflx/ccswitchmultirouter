## 日本語

### リリース概要

このリリースでは、前回の GitHub Release で欠けていた統合履歴を公開し、モデルカタログ、MultiRouter、上流変更の移植、リリースツールチェーンをまとめて完成させます。上流ファイルで fork 固有の OAuth、ルーティング、トラフィックポリシー、Sub-Agent V2、4 言語 UI を上書きせず、機能単位で統合しています。

### モデルカタログと無料モデルの絞り込み

- 完全に成功した `/models` 同期では、上流に明示的に結び付いた古いモデルを削除します。明示的な上流バインドを持たない手動モデルは保持します。
- fallback key と有効なすべてのグループ key を取得して重複排除します。1 つでも失敗した場合は成功結果だけを統合し、不完全な結果では削除しません。
- Provider フォーム、4 ステップのウィザード、公式 OAuth、ルートワークスペースで同じ同期規則を使用します。
- `free` などを入力すると既存の一覧領域が一時的な検索結果になります。Include/Exclude Filtered の実行後は検索を消去し、保存済みの Included/Excluded ビューへ移動します。
- 削除されたモデルは固定ルート、カスタム順序、投影候補、spawn-agent 優先候補からも除外されます。

### MultiRouter UI

- ウィザードは fallback key だけでなく、有効なグループ認証情報をすべて取得します。
- モデルソース選択、自動同期とプロトコル確認、モデル選択とルートプレビュー、有効化と実リクエスト確認の全 4 ステップを再監査しました。
- モバイルでは 2×2 のステップナビゲーションと全幅コンテンツを使用し、デスクトップ用サイドバーによるレイアウト崩れを修正しました。
- 英語 UI の MultiRouter 入口、ソース選択、プリセット、詳細設定、プレースホルダーが中国語へフォールバックしないよう修正し、4 言語すべてのキーを揃えました。

### 意図的に一括統合しなかった項目

- OAuth/JWT 全体の書き換えは、アカウント分離と認証保持を壊さないよう、将来 hunk 単位で移植します。
- Pi の usage dedup は、この fork に `session_usage_pi.rs` がないため対象外です。
- 既に同等の fork 実装がある BigStrongSun の変更は重複して取り込みません。

### リリース基盤

- updater、比較 URL、製品リンク、トレイリンクを `tngflx/ccswitchmultirouter` に統一し、updater 公開鍵をローテーションしました。
- Node はローカルと全 workflow で **22.23.2**、pnpm は最新 v11 の **11.24.0** に統一しました。
- GitHub Release 本文は英語、中国語、日本語のノートを自動結合し、1 行だけのフォールバック説明を使用しません。

### アップグレード時の注意

- 完全同期は上流バインド済みモデルに対して権威的です。手動モデルは明示的な上流バインドなしで管理してください。
- 認証情報の一部が失敗した場合、未一致モデルは保持されます。認証を修復して再同期すると権威的な削除が行われます。
- モデル順序、モデルメニュー、MultiRouter、Sub-Agent プロトコルを変更した後は Codex Desktop/app-server を再起動してください。
