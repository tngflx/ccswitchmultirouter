## 简体中文

### 本次发布重点

本版本补齐上一个 GitHub Release 缺失的完整说明，并正式收口本 fork 已完成的模型目录、MultiRouter、上游移植与发布工具链工作。下面不仅列出功能，也明确记录每项上游改动如何接入现有架构，以及哪些内容没有被整包覆盖。

### 模型目录与免费模型筛选

- **权威同步：** 当供应商 `/models` 完整成功返回时，已经绑定真实上游模型、但远端不再提供的目录行会被删除；没有显式上游绑定的手工模型会保留。
- **多凭据安全：** 同步会读取 fallback key 和所有启用的分组 key，并按模型 id 去重。任一凭据失败时只合并成功结果，不删除未匹配模型，避免误删仅失败账号可见的模型。
- **所有入口一致：** Provider 表单、四步 MultiRouter 向导、官方 OAuth 同步和路由工作台现在共用同一套“完整结果才允许删除”的规则。
- **临时筛选：** 输入 `free` 或其他关键词时，原模型列表区域临时显示匹配项，匹配范围包括模型名、上游模型名和菜单显示名。点击“纳入筛选结果”或“排除筛选结果”后，操作只作用于当前匹配项，搜索词会被清空，并自动进入真实的“已纳入”或“已排除”列表。
- **下游清理：** 远端已删除的模型也会从固定路由选择、模型顺序、投影候选和 spawn-agent 优先列表中移除；仍存在模型的别名、排除状态、能力声明和用户顺序保持不变。

### MultiRouter 与 Provider UI

- MultiRouter 向导现在会读取每一个启用的分组凭据，不再只读取 fallback key；部分凭据失败时会给出明确提示并禁止破坏性删除。
- 已重新审计四个步骤：选择模型源、自动同步与协议验证、选择模型并预览路由、保存启用并进行真实请求验证。
- 移动端改为 2×2 步骤导航和全宽内容区，不再由桌面侧栏把正文挤成逐字换行。
- 英文界面的主页入口、模型源选择框、预设选择器、说明文字、高级配置和输入占位符不再回退到中文。新增文案同时更新英文、简体中文、繁体中文和日文。
- Provider 显示保持紧凑，但稳定 Provider id 与真实上游模型 id 仍用于诊断和路由。

### 已整合的 Codex 路由、探测与恢复能力

- Schema v2 MultiRouter 由目标 Provider 持有地址、凭据、协议、上下文和能力；Route 只保存模型选择、别名、前缀和认证策略。
- 深度协议探测会对 Responses 与 Chat 分别执行基础 JSON、SSE、reasoning、强制工具调用和工具续传阶段，并提供脱敏的逐模型进度与故障分类。
- 已验证的 Provider 协议 profile 会同步到依赖路由，并在运行时继承，不会把凭据复制进 Route。
- Codex Desktop 模型选择器投影、Guardian/CDP 重新注入、模型/Provider 标签样式、排序和 spawn-agent 候选继续使用 Provider 目录作为事实来源。
- 分层恢复将安全的语义前重连与有限次数的 Codex Desktop `continue` 提交分开。
- 分组 API Key、reasoning content mode、Codex 流量策略、官方认证保留、Hosted Tool 诊断和 Sub-Agent V2 都保持为本 fork 的能力，没有被上游文件覆盖。

### 明确未整包合并的内容

- 完整 OAuth/JWT 重写仍需以后逐 hunk 适配，不能覆盖 fork 的账号隔离、认证保留和 Provider 流程。
- Pi usage dedup 不适用，因为本 fork 没有 `session_usage_pi.rs`。
- BigStrongSun 最近的 probe/reasoning/profile 改动，在本 fork 已有等价适配时不重复引入。

### 同期包含的其他改动

- OpenCode Go 套餐用量支持 rolling、weekly、monthly 窗口与防御性解析。
- 新增支持 tab-aware 启动的 Otty 终端。
- 当同步数据库没有启用 Prompt 时，恢复流程不再擦除本地未托管 Prompt 文件。
- 更新检查可以显示当前构建落后本 fork main 的精确 commit 数。
- 可刷新已有模型元数据，同时保留别名、排除状态、reasoning override 和用户排序。
- 当向导已经负责协议探测时，Provider 写入可显式跳过隐藏的自动深度探测。

### 发布与更新基础设施

- Updater endpoint、compare URL、产品链接和托盘链接统一指向 `tngflx/ccswitchmultirouter`。
- Updater 公钥已轮换到本仓库 Release environment 使用的密钥，私钥文件已加入 `.gitignore`。
- 本地与全部 CI/Release workflow 统一使用 **Node 22.23.2**；pnpm 固定为最新 v11 **11.24.0**，并通过 package engines 拒绝不兼容的大版本。
- GitHub Release 会自动拼接英文、中文和日文说明，不再在说明文件缺失时只显示一行自动发布提示。

### 升级说明

- 完整同步现在会删除远端已消失的上游绑定模型；需要长期手工保留的模型请不要设置显式上游绑定。
- 分组凭据部分失败时，本次同步不会删除未匹配模型。修复凭据后再次同步，才能得到权威清理结果。
- 修改模型顺序、模型菜单可见性、MultiRouter 启用状态或 Sub-Agent 协议后，请重启 Codex Desktop/app-server 并新建会话。
