# Engineering Memory

`journal.md` records significant root causes, design decisions, upstream-port verdicts, and release evidence, newest first. Keep entries concise and include exact verification results. Never rewrite old entries; add a correction when evidence changes.

`root-notes-archive.md` is the single historical archive for the former
root-level `memory-*.md` and ad-hoc engineering notes. Do not create another
dated root note. Codex-native memory can supplement context for an individual
assistant session, but it is not versioned or reviewable by collaborators and
therefore cannot replace this journal or the decision records.
