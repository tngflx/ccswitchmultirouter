# Engineering Memory

`journal.md` records significant root causes, upstream-port verdicts, and milestone
verification evidence, newest first. Record an outcome once, not every test rerun
or chat continuation. Keep entries concise and include exact verification results.
Never rewrite historical outcomes; add a correction when evidence changes.

`root-notes-archive.md` is the single historical archive for the former
root-level `memory-*.md` and ad-hoc engineering notes. Keep it frozen and do not
create another dated root note. Durable architectural rationale belongs in the
existing topic guides rather than per-fix decision files.

Native memory may carry disposable assistant recaps and navigation hints. Required
rules, unresolved work, and reproducible verification evidence must remain explicit
project records; recalled context alone is not evidence that a feature works.
